# Domain Docs

Before exploring code, read `CONTEXT.md` at the repo root.
Also read ADRs in `docs/adr/` that relate to the work.

If these files do not exist, continue silently.

This repo uses a single-context layout:

- `CONTEXT.md`: domain terms and system context
- `docs/adr/`: architecture decisions

Use terms from `CONTEXT.md` in issue titles, plans, and tests.
If a needed term is missing, note the gap.
If a change conflicts with an ADR, call out the conflict.
