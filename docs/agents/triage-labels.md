# Triage Labels

Use these labels for the five triage roles.

| Role | Label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | A maintainer must review the issue |
| Needs information | `needs-info` | The reporter must provide more information |
| Ready for agent | `ready-for-agent` | The issue is ready for an agent |
| Ready for human | `ready-for-human` | A human must implement the work |
| Won't fix | `wontfix` | The issue will not be fixed |
